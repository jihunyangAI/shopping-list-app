# 🛒 쇼핑 리스트

설치 없이 브라우저에서 바로 쓰는 간단한 쇼핑 리스트 웹 앱입니다.

## 기능

- **추가**: 입력 후 Enter 또는 `추가` 버튼 (앞뒤 공백 제거, 빈 값 무시)
- **체크**: 담은 물건 체크 → 취소선 표시, "N개 중 M개 담음" 진행 상황
- **삭제**: 항목별 ✕ 버튼, `체크한 항목 모두 삭제`
- **저장**: Supabase 데이터베이스(`shopping_item` 테이블)에 저장되어 어느 기기에서 열어도 같은 목록
- 이전 버전에서 브라우저(localStorage)에 저장해 둔 목록은 처음 열 때 자동으로 DB로 옮겨짐
- 다크 모드·모바일 화면 대응

## 실행

`index.html` 파일을 브라우저로 열면 됩니다. 서버나 빌드가 필요 없습니다.

## 데이터베이스

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `id` | uuid | 기본키 |
| `name` | text | 물건 이름 (1~100자) |
| `done` | boolean | 체크 여부 |
| `created_at` | timestamptz | 추가 시각 (목록 정렬 기준) |

로그인 없이 쓰는 **공용 목록**입니다. 주소를 아는 누구나 항목을 보고, 추가하고, 지울 수 있습니다.

## 테스트

Playwright로 추가·체크·삭제·저장·기존 목록 이전·오류 처리 18개를 자동 테스트합니다. 테스트는 Supabase 요청을 가짜 응답으로 바꿔 실행하므로 실제 DB를 건드리지 않습니다. 설치된 Chrome을 사용합니다.

```bash
npm install
npm test
```
